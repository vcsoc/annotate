Annotate 1.0

Point at anything on your screen — and tell your AI what to change.

Annotate takes a screenshot of a whole application, highlights the area you mark, and keeps your note with it. Collect a few, then send them to Pi, Claude Code, Codex, OpenCode, ChatGPT, Claude or almost any other AI tool — or copy them into a document.

＋ Capture→Mark an area→Write a note ✓→Send ➤
✎ Annotate Console⌘⇧A
＋ Capture (1s)
✎ Freehand
Send to harness / sessionPi · my-app : ~/projects/
#1 Make this button blue and move it to the right
#2 2 marks · 1. Typo here 2. Use a softer grey
Follow-up ▾⧉🗑➤ 2

📸 The whole app, not a crop

Your AI sees the full window with your highlight, so it understands the context.

🧭 Works with any harness

Terminal agents, desktop chat apps, a browser app, or just a folder.

📋 Paste anywhere

Copy an annotation into Word, PowerPoint, Google Docs, a PDF or a chat.

🔒 Nothing is sent by itself

Annotations stay in the Console until you press Send.

Install Annotate one command

Copy the line for your computer into a terminal and press Enter. It downloads Annotate, installs it, and puts the annotate command on your PATH.

macOS / Linux — Terminal
curl -fsSL https://raw.githubusercontent.com/vcsoc/annotate/HEAD/install.sh | sh
Windows — PowerShell
powershell -c "irm https://raw.githubusercontent.com/vcsoc/annotate/HEAD/install.ps1 | iex"
Already use Rust? — any OS
cargo install --git https://github.com/vcsoc/annotate annotate --locked
Want Pi connected straight away? Add the integration to the same line:
curl -fsSL https://raw.githubusercontent.com/vcsoc/annotate/HEAD/install.sh | sh -s -- --integrations pi

If there is no ready-made download for your system, the installer builds Annotate for you. It installs Rust and the required system libraries first, asking before it does, and the first build takes a few minutes. Annotate is a native Rust + Tauri app, so no Node.js or npm is involved.

To remove it later: curl -fsSL https://raw.githubusercontent.com/vcsoc/annotate/HEAD/install.sh | sh -s -- --uninstall. Your settings and saved annotations are kept.

Your first annotation ≈ 1 minute

Open the app you want to talk about (a web page, an editor, anything), then open Annotate. A narrow Console panel docks to the right of your screen.

  1. Click “＋ Capture”The Console hides. You have one second to get the app ready (for example, reopen a menu). Pressing ⌘/Ctrl+Shift+A does the same with no countdown.
  2. Mark the areaDrag over the part of the app you mean. Freehand draws a loop; Area draws a rectangle. Switch at the top of the screen, or press A / F. Esc cancels.
  3. Write your noteA small note box opens right next to your mark. Write what you want, as you would to a colleague: “Make this button blue and move it to the right.”
  4. Save with ✓Click ✓ or press ⌘/Ctrl+Enter. The annotation appears in the Console. Nothing has been sent yet.
  5. Repeat as often as you likeCollect up to 8 annotations (you can raise that to 12 in Settings).
  6. Choose where it goes, then SendPick a destination in Send to harness / session and press the green ➤. Everything is delivered together.
Each saved picture is the entire application window with your mark drawn on it. Check it for passwords or private messages before you send.

Annotate + Pi ≈ 3 minutes

With the Pi integration, every open Pi session shows up in Annotate as a live destination, and the /annotate command in Pi opens the Console aimed at that session. Your annotations arrive in Pi as a normal message with all the screenshots attached.

Step 1 — Remove the old pi-annotate package (if you have it)

The new integration replaces the older pi-annotate extension. Both add an /annotate command, so only keep one.

pi remove https://github.com/vcsoc/pi-annotate.git
Not ready to switch yet? Pi sessions that still run the old pi-annotate already appear in Annotate's destination list, and sending to them works. You can skip to Step 3.

Step 2 — Install the Pi integration

Either in the app: ⚙ Settings → Harnesses → Integrations → Pi → Install.

Or in a terminal:

annotate integrations install pi

This adds one file, ~/.pi/agent/extensions/annotate/index.ts. Then, in each Pi session that is already open, run:

/reload

Step 3 — Use it

  1. In Pi, type /annotateAnnotate opens (or comes to the front) and its destination is set to this Pi session.
  2. Capture and write notesMark the problems in your app as described in Your first annotation.
  3. Choose “Send as”Follow-up waits until Pi finishes what it is doing. Queued (steering) is picked up at the next step of the current task.
  4. Press ➤ SendPi receives one message with every screenshot and note, and starts working.

You (in Annotate): #1 “This table header should stay visible when I scroll.” #2 “Use our brand blue here.”

Pi: I can see both screenshots. The header is in src/components/Table.tsx — I’ll make it sticky, and update the button colour in theme.css…

In PiWhat it does
/annotateOpen the Console and aim it at this session (your saved annotations are kept).
/annotate helpA short reminder of the workflow.
/annotate stopClose the Console (unsent annotations are discarded).
Have several Pi sessions open? They all appear in the dropdown as Pi · project-name. Pick the one that should do the work. Your model must be able to read images.

Claude Code, Codex & Gemini CLI

These tools connect through Annotate's built-in MCP server. Once installed, every running session appears as a live destination, and the AI can even ask you to annotate something.

Install

annotate integrations install claude-code     # Claude Code (MCP + skill)
annotate integrations install codex           # Codex CLI   (MCP + skill)
annotate integrations install gemini          # Gemini CLI  (MCP)

…or click Install next to each in ⚙ Settings → Integrations. Restart any session that was already open.

Example: let the AI ask you

You: The settings page looks wrong — I'll show you.

Claude: (calls request_annotations — the Annotate Console opens, aimed at this session)

You: capture, mark the problems, press Send.

Claude: Thanks — I can see the overlapping labels in screenshot 1 and the cut-off button in screenshot 2. Fixing both…

Example: send first, then tell the AI

Choose Claude Code · my-project in the destination list and press Send. Then say “I sent you some annotations” — the AI collects them with get_annotations.

Using another MCP-capable tool (Cursor, Claude Desktop, VS Code, Goose…)? Click ⧉ MCP config in Settings and paste the snippet into that tool's MCP settings.

OpenCode

annotate integrations install opencode

Restart OpenCode. While it runs it appears as OpenCode · project in the destination list, and batches are sent straight into the session you used most recently, with every screenshot attached.

ChatGPT, Claude & other desktop apps

Installed chat apps — ChatGPT, Claude, OpenCode Desktop, Open WebUI, LM Studio, Ollama, Jan, Msty, Perplexity and more — are listed under Desktop apps. No integration needed.

  1. Pick the appFor example ChatGPT app.
  2. Choose “Send as”Paste (review, then send) types everything into the app and lets you check it. Paste and send also presses Enter.
  3. Press ➤ SendAnnotate brings the app to the front and pastes your notes and each screenshot.
On macOS, allow Annotate under System Settings → Privacy & Security → Accessibility the first time — it needs this to press ⌘V for you. Your previous clipboard text is restored afterwards.

Open WebUI in a browser instead? Choose Open WebUI (browser) and set its address in ⚙ → Harnesses (default http://localhost:3000).

Start a new terminal session

No session open yet? Under Start in a terminal you'll find every AI command-line tool Annotate detected (Pi, Claude Code, Codex, OpenCode, Gemini CLI, Copilot CLI…).

  1. Choose e.g. “Claude Code — new session”
  2. Click the 📁 chip and choose your project folderThe tool will start there.
  3. Press ➤ SendA new terminal window opens and the tool starts with a request to read your annotations.

Pick your favourite terminal (Terminal, iTerm, Ghostty, WezTerm, kitty, Windows Terminal…) in ⚙ → Harnesses → Terminal for new sessions.

Any agent that can run a shell command

Some tools have no plugin system and no MCP. As long as the AI can run commands, it can use:

annotate wait --project "$PWD" --timeout 900

This opens the Console aimed at that terminal, waits until you press Send, then prints your notes and the screenshot paths for the AI to read. Install the Agent Skills integration and many agents will know to do this automatically when you say “let me show you”.

annotate integrations install agent-skills

Copy into documents & slides

Writing a bug report, a design review or a slide deck? Every annotation can go to the clipboard.

  • ⧉ Copy on an annotation (or ⌘/Ctrl+C in the Console) copies that one.
  • The ⧉ button next to 🗑 copies all of them.

Then paste with ⌘/Ctrl+V wherever you like. Choose the style in ⚙ → Clipboard → Copy format:

FormatBest for
Image and notes (default)Word, PowerPoint, Pages, Google Docs, Notion, email — you get the screenshot with its note.
Screenshot with the note printed under itPDF editors, whiteboards, image tools — one picture that includes the note.
Screenshot onlyWhen you only want the picture.
Notes onlyTickets, chat messages, plain text.

Several marks in one screenshot

Found three problems on the same screen? Keep them in one picture with numbered marks.

  1. Double-click an annotation's screenshot(or click ＋ Mark). It opens in a larger window beside the Console.
  2. Draw on the screenshotEach new mark gets a number badge ①, ②, ③…
  3. Write a comment for each markThe list under the picture has one box per number.
  4. Click DoneThe AI receives a numbered list that matches the badges in the image.
Send stays disabled until every mark has a comment, so nothing gets lost.

Shortcuts & settings

  • Change the capture shortcut: ⚙ → click the Capture shortcut field and press the new keys. It works immediately.
  • Global shortcut off means the shortcut only works while the Console is focused.
  • Countdown: 0–30 seconds before Capture, so you can open a menu first.
  • When a mark crosses the app edge: Trim keeps only the app; Extend widens the screenshot to include your whole mark.
  • Keep the Console open after Send: handy if you annotate all day.

Linux with Hyprland or sway? Annotate adds a temporary compositor key binding that runs annotate capture. You can also bind it yourself:

# Hyprland
bind = SUPER SHIFT, A, exec, annotate capture
# sway
bindsym Mod4+Shift+a exec annotate capture

Add your own harness

Using a tool Annotate doesn't know? Describe it in ~/.annotate/harnesses.json and it appears in the destination list after ↻ Detect harnesses.

~/.annotate/harnesses.json
[
  { "id": "aider", "name": "Aider", "kind": "terminal",
    "command": ["aider", "--message", "{prompt}"] },

  { "id": "mychat", "name": "My Chat App", "kind": "desktop",
    "app": ["My Chat App"], "keys": "mod+l" },

  { "id": "teamchat", "name": "Team chat", "kind": "web",
    "url": "https://chat.example.com" }
]
  • {prompt} becomes a one-line request pointing at your saved annotations.
  • keys is pressed after the app opens (to focus its chat box). mod = ⌘ on Mac, Ctrl elsewhere.

Troubleshooting

“No application windows are available” or black screenshots (macOS)

Allow Screen Recording for Annotate in System Settings, then quit and reopen Annotate.

My Pi session isn't in the list

Run /reload in that Pi session (after installing the integration). Check with annotate harnesses — live sessions are listed first.

Pi says it needs a vision-capable model

Switch the Pi session to a model that accepts images, then press Send again. Your annotations are still in the Console.

Pasting into ChatGPT / Claude does nothing

Allow Accessibility for Annotate (macOS). If the app opens slowly, raise ⚙ → Harnesses → Desktop app paste delay.

The shortcut doesn't work

Another app may use the same keys. Record a different one in ⚙ Settings — an error appears under the field if it can't be used.

Two /annotate commands in Pi

Remove the old package: pi remove https://github.com/vcsoc/pi-annotate.git, then /reload.

Still stuck? Open an issue at github.com/vcsoc/annotate and include the message shown in the Console. Developed by Chris Visser — github.com/vcsoc.
