⋮⋮✎ Annotate Console

Capture → mark an app area → add a note → ✓ save here. Send or copy when ready.

Settings

Shortcut
ⓘClick the field and press the key combination. It is saved and applied immediately. Backspace restores the launch default shown in the field. The shortcut starts a capture with no countdown.

ⓘOn: the shortcut starts an annotation from any app. Off: it works only while the Annotate Console is focused. Applied immediately.
Capture
ⓘTool used by Capture and the keyboard shortcut. You can still switch between Freehand and Area while marking.
ⓘWhat happens when a mark goes past the edge of the app. Trim: the mark is cut to the app window where you started drawing. Extend: the screenshot grows to include the whole app plus the part of the mark outside it.
ⓘWait before Capture or Retake so you can reopen a menu. 0 means no delay. The keyboard shortcut always captures immediately.
ⓘHyprland and sway only. Live marks the app without freezing it, then captures. Preserved freezes the desktop first so open menus stay visible. Other desktops always use live capture.
Batch
ⓘDefault 8, range 1–12. The 24 MiB transport limit still applies. Existing annotations are never removed by this setting.
ⓘFor destinations that support it. Follow-up waits for the current task to finish. Queued (steering) is read at the next tool boundary.
ⓘOff: the Console closes after a successful Send. On: it stays open (and keeps the capture shortcut) for the next batch.
Clipboard
ⓘWhat ⧉ Copy puts on the clipboard. Image and notes: rich editors (Word, PowerPoint, Pages, Docs) get the screenshot with its note; image-only apps get the screenshot. Screenshot with note: one image with the note printed underneath, ideal for PDF editors. Several annotations are stacked into one image where needed.
Harnesses
ⓘConsole harnesses (Pi, Claude Code, Codex, OpenCode, Gemini CLI…) without a live session are started in this terminal, in the chosen project folder.
ⓘUsed by the Open WebUI (browser) destination.
ⓘDesktop apps are brought to the front, then the notes and screenshots are pasted. Increase this if the app needs longer to open.
IntegrationsⓘBuilt-in extensions, plugins, MCP server and skill. Installed integrations make open harness sessions appear as live destinations and let agents ask you for annotations.

    Appearance
    ⓘTimeline feed: a narrow panel that docks to a screen edge; double-click an annotation to open it and add numbered marks. Command pill: a compact floating bar that opens into a tray.
